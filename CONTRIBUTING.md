# Contributing to Crowd Sense Pro

We love your input! We want to make contributing to Crowd Sense Pro as easy and transparent as possible.

## Development Process

We use GitHub to host code, to track issues and feature requests, as well as accept pull requests.

### Pull Requests

1. Fork the repo and create your branch from `main`
2. If you've added code that should be tested, add tests
3. Ensure the test suite passes
4. Make sure your code lints
5. Issue that pull request!

### Any contributions you make will be under the MIT Software License

In short, when you submit code changes, your submissions are understood to be under the same [MIT License](LICENSE) that covers the project.

## Reporting Bugs

### Security Disclosures

**Do not** open public issues for security vulnerabilities. Please email the maintainers instead.

### General Bug Reports

When reporting bugs, include:

- **Summary**: A quick summary of the issue
- **Steps to Reproduce**: How to reproduce the issue step-by-step
- **Expected Behavior**: What should happen
- **Actual Behavior**: What actually happens
- **Environment**: OS, Python version, Node version
- **Logs**: Any error messages or logs

## Feature Requests

We'd love to hear your ideas! Please:

1. Use a clear and descriptive title
2. Provide a step-by-step description of the suggested feature
3. Provide specific examples to demonstrate the feature
4. Explain why this enhancement would be useful
5. List some other tools/projects where this feature exists

## Code Style

- Follow PEP 8 for Python
- Use 2 spaces for JavaScript/React
- Use type hints in Python where practical
- Write meaningful commit messages

## Testing

Before submitting a PR:

```bash
# Backend
cd backend
pytest

# Frontend
cd frontend
npm test
```

## Git Commit Messages

- Use the present tense ("Add feature" not "Added feature")
- Use the imperative mood ("Move cursor to..." not "Moves cursor to...")
- Limit the first line to 72 characters or less
- Reference issues and pull requests liberally after the first line
